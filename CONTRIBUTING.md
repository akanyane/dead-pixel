# Contributing to DEAD PIXEL

All help is welcome: balancing, new enemies, terminal commands, translations or bug fixes.

## Setting up

```bash
git clone https://github.com/akanyane/dead-pixel.git
cd dead-pixel
npm install
npm run dev
```

With `npm run dev`, the game object is exposed as `window.__g`, which makes testing from the browser console easy:

```js
__g.god = true;        // invincibility (same as opening with ?god in the URL)
__g.startLevel(3);     // jump to a level (0 to 4)
__g.beginPlay();       // skip the story screen
__g.player.ram = 512;  // full RAM to test the terminal
```

Before opening a PR, run the build, which also runs the typecheck:

```bash
npm run build
```

The project has no automated tests yet, so play the part you changed.

## Commit messages

Versions and `CHANGELOG.md` are generated by [release-please](https://github.com/googleapis/release-please) from the commits. That's why messages must follow [Conventional Commits](https://www.conventionalcommits.org/), written in English:

| Prefix | When to use it | Version bump |
| --- | --- | --- |
| `feat:` | Something new for the player | Minor (`1.1.0`) |
| `fix:` | A bug fix | Patch (`1.0.1`) |
| `perf:` | A performance improvement | Patch (`1.0.1`) |
| `feat!:` or a `BREAKING CHANGE:` footer | An incompatible change, such as breaking old saves | Major (`2.0.0`) |
| `docs:`, `chore:`, `refactor:` | Everything else | None |

Examples:

```text
feat: add a traceroute command to the terminal
fix: stop items from spawning inside walls
```

## Where things live

| I want to... | File |
| --- | --- |
| Balance enemies, weapons, perks or waves | `src/game/data.ts` |
| Add a skin | `SKINS` in `src/game/data.ts`, plus its text in `src/game/i18n.ts` |
| Add an achievement | `src/game/achievements.ts`, plus its text in `src/game/i18n.ts` |
| Change or translate text | `src/game/i18n.ts` |
| Add a terminal command | `src/game/terminal.ts` |
| Change enemy and boss AI | `src/game/enemies.ts` |
| Change damage, projectiles and controls | `src/game/combat.ts` |
| Work on gore and particles | `src/game/fx.ts` |
| Add or change an arena | `src/game/map.ts` |
| Draw sprites | `src/game/sprites.ts` |
| Work on sound effects and music | `src/core/audio.ts` |

Every visible string lives in `src/game/i18n.ts`, in all three languages. The font is a custom bitmap: besides ASCII, it only has the accents used in Portuguese and Spanish, plus `¡` and `¿`.

The project uses no external assets: all art and sound come from code. Please keep it that way.

When creating content, make something original. Don't recreate characters, levels or art from existing games.
